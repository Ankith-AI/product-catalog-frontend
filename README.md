# Product catalogue Front-end 

This project is a web application interface for a product catalogue, built using Next.js and React components, shadcn UI, jotai state management, and Supabase for Authentication and database.

## Features

- **Hero Section**: Engaging introduction section to captivate user interest.
- **Slider**: Interactive image slider to showcase products or promotions.
- **Featured Section**: Highlighted content area to display featured products or services.
- **Contact Form**: User-friendly contact form to facilitate user interaction and queries.
- **Navigation and Footer**: Includes a consistent navigation bar and footer for improved user experience.
- **Theme Support**: Supports both light and dark themes, adapting based on user preference.

## Components

The following components make up the core structure of the application:

- `Hero`: Displays the main hero banner for the landing page.
- `Slider`: Interactive slider to highlight products or key visuals.
- `Featured`: Section to display featured items with emphasis.
- `ContactForm`: Contact form to collect user inquiries.
- `NavigationBar`: Navigation bar component for site-wide navigation.
- `Footer`: Footer component for additional links and information.

## Styling

- **Fonts**: Utilizes Google Fonts with `Playfair Display` for headlines and `Source Code Pro` for code or technical details.
- **Global Styles**: Configured using `globals.css` for base styling.

## Usage

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Use `npm run dev` to start the development server.
4. Open [http://localhost:3000](http://localhost:3000) in a browser to view the application.

## Technologies Used

- **React**: Component-based structure.
- **Next.js**: Framework for optimized performance and routing.
- **TypeScript**: For type safety and improved developer experience.
- **CSS Modules**: Scoped and modular styling.
- **jotai**: State management
- **Supabase**: Authentication and data storage.
